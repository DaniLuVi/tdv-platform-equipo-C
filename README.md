# Instrucciones de juego (Stella & Galaxy)

## Controles generales

Para una completa posibilidad de jugabilidad se debe disponer de teclado y ratón.

El teclado será más importante, pero el ratón se deberá de necesitar para poder hacer click en algunos botones y poder seleccionar el nivel que se quiere jugar, guardar el progreso de una partida, ...

Para hacer más dinámico y menos pesado, cada vez que pierdes en un nivel aparece una vista de nivel no superado, en el que se nos indica si queremos repetir el nivel o volver al mapa de niveles. En este punto, para que no tengas que hacer click cada vez que un personaje "muere", se ha incluido un atajo por el que pulsando la tecla ENTER, hace la función de "Repetir nivel" o de "Ir al siguiente nivel" que se realiza al hacer click en esos botones.

## Mecánicas de jugabilidad de los niveles

Para los niveles, los controles son bastante sencillos y fáciles de asociar. 

En este juego hay dos personajes que hay que controlar. Cada personaje se mueve con unas teclas especificas, en las que el personaje se puede mover hacia ambos lados o saltar hacia arriba:
  - Stella (el personaje rojo) se controla mediante las teclas: A (izquierda), D (derecha) y W (saltar)
  - Galaxy (el personaje azul) se controla mediante las teclas: Flecha izquierda (izquierda), Flecha derecha (derecha) y Flecha arriba (saltar)

Se deberá de ir completando los niveles uno a uno hasta finalizar el juego.
